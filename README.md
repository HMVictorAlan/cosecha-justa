# Cosecha Justa

Maqueta del sitio web de **Cosecha Justa**, un modelo de negocio inclusivo que compra a pequeños productores la cosecha sana que no se vendió y les enseña a transformarla en productos con mejor precio.

Actividad 2 de la materia *Diseñar para compartir* (UVM). Diseñado con la metodología de accesibilidad **POUR** (Perceptible, Operable, Comprensible y Robusto).

**Sitio en línea:** https://hmvictoralan.github.io/cosecha-justa/

- HTML, CSS y JavaScript, sin librerías.
- Botón de accesibilidad: tamaño de texto, alto contraste, resaltar enlaces, espaciado y lectura en voz alta.
- Las fotografías vienen de Wikimedia Commons con licencia libre. Los créditos están en [accesibilidad.html](accesibilidad.html#creditos).
